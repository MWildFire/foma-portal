## Суть

Программы строятся из нескольких конструкций: последовательность (инструкции выполняются по порядку), ветвление (выбор между путями), повторение (многократное выполнение кода) и подпрограммы (именованные функции с параметрами и возвращаемыми значениями). Написать верную программу — значит расставить инструкции в правильном порядке, выбрать подходящий вид цикла или условия и разбить код на функции, которые можно проверять и повторно использовать. Эти конструкции встречаются почти в каждом программистском задании второй части экзамена.

## Объяснение

**Последовательность и порядок.** Инструкции выполняются одна за другой в порядке записи, поэтому каждая строка использует значения, которые существуют в этот момент. Неверный порядок чаще даёт неверный результат, а не ошибку: итог, напечатанный до расчёта, показывает начальное значение. Нужно следить за двумя проблемами: <Term id="b2-3-infinite-loop"/> — это цикл, условие окончания которого никогда не выполняется, обычно из-за того, что счётчик не меняется, и неверный ввод пользователя, который может сломать программу, если её не проверять.

**Ветвление.** <Term id="b2-3-selection"/> — это принятие решений в коде, обычно с помощью оператора if. Цепочка if, elif, else проверяет условия по очереди и выполняет только первый блок, условие которого истинно; блок else выполняется, когда ни одно условие не истинно. В условиях используются операторы сравнения, например == (равно) и != (не равно), а также операторы «больше» и «меньше». Условия можно объединять связками and, or и not. Если должна выполниться только одна ветка, лучше использовать одну цепочку, а не несколько отдельных if, ведь каждый отдельный if проверяется сам по себе.

**Повторение.** <Term id="b2-3-repetition"/> — это многократный запуск блока кода. <Term id="b2-3-while-loop"/> повторяется, пока его условие остаётся истинным. Его используют, когда заранее неизвестно, сколько повторов понадобится, например когда пароль запрашивают до тех пор, пока он не введён верно. Условие проверяется перед каждым повтором, поэтому блок может не выполниться ни разу. <Term id="b2-3-for-loop"/> повторяется заданное число раз, например по одному разу для каждого значения range(0, 11) или для каждого элемента списка. В Python range(0, 11) даёт значения от 0 до 10, потому что конечное значение никогда не включается.

**Подпрограммы.** <Term id="b2-3-function"/> — это именованный блок кода, который выполняет одну задачу. В её заголовке перечислены <Term id="b2-3-parameter"/>, которые получают значения, а оператор return отправляет результат вызвавшему коду в виде <Term id="b2-3-return-value"/>. Каждое значение, переданное при вызове, — это <Term id="b2-3-argument"/>, его также называют фактическим параметром. Переменная, созданная внутри функции, называется локальной и существует только внутри неё. Глобальная переменная объявляется вне всех функций и доступна во всём коде.

<Callout kind="define">Параметр — это переменная, названная в определении функции. Аргумент — это значение, переданное при вызове. Параметры относятся к определению, а аргументы — к вызову.</Callout>

**Модульность.** <Term id="b2-3-modularization"/> означает разбиение кода на функции или модули. Код становится проще читать, потому что у каждой части одна понятная задача; его легче проверить отдельно, повторно использовать в других программах и изменять, потому что правка вносится в одном месте.

## Разбор примера

Программа ниже сочетает функцию, цикл и ветвление. Определите вывод строка за строкой, прежде чем читать шаги.

```python
def label(score):
    if score >= 50:
        return "pass"
    return "fail"

scores = [72, 45, 50]
passes = 0
for s in scores:
    result = label(s)
    print(s, result)
    if result == "pass":
        passes = passes + 1
print(passes)
```

<Steps>
<Step>Функция label получает один аргумент — балл — и возвращает "pass", если балл равен 50 или больше.</Step>
<Step>Цикл for берёт каждое значение по очереди, поэтому label вызывается три раза.</Step>
<Step>Для 72 функция возвращает "pass", поэтому цикл печатает "72 pass", а passes становится равным 1.</Step>
<Step>Для 45 функция возвращает "fail", поэтому цикл печатает "45 fail", а passes остаётся равным 1.</Step>
<Step>Для 50 функция возвращает "pass", потому что 50 входит в условие, поэтому цикл печатает "50 pass", а passes становится равным 2. После цикла print(passes) выводит 2.</Step>
</Steps>

<Reveal title="Показать вывод">72 pass, затем 45 fail, затем 50 pass, затем 2.</Reveal>

## Как это спрашивают

Командные слова этой темы встречаются в таких заданиях:

- **Объясните (Explain)**: подробный ответ с причинами или следствиями, например почему возникает бесконечный цикл.
- **Проведите различие (Distinguish)**: покажите разницу между двумя понятиями, например между параметром и аргументом.
- **Обоснуйте (Justify)**: приведите верные причины выбора, например почему для описанной задачи нужен цикл while, а не for.
- **Кратко опишите (Outline)**: короткий рассказ без обоснований, например о преимуществах модульности.
- **Вычислите (Calculate)**: числовой ответ с показанными этапами, например заполненная таблица трассировки.
- **Укажите (State)**: вывод программы или короткий ответ без объяснений.
- **Составьте (Construct)**: полный рабочий код на Python, когда просят написать функцию или программу.

<Callout kind="exam">Если в задании на «Составьте» нужно вернуть значение, функция должна его вернуть: одного вывода на экран недостаточно. Проверьте, что в каждом цикле есть переменная, которая меняется и приводит к условию окончания, и что каждое ветвление покрывает свой случай.</Callout>

## Типичные ошибки

- Не печатай внутри функции, когда задание требует вернуть значение. Текст появится на экране, но вызывающий код не сможет его использовать, если функция не вернёт результат.
- Не пиши несколько отдельных if там, где нужна одна цепочка if, elif, else: тогда может выполниться сразу несколько блоков.
- Не забывай менять счётчик в цикле while, иначе цикл никогда не закончится.
- Не жди, что range(0, 11) включит 11: конечное значение исключается.
- Не путай параметры и аргументы. Параметр — это имя в определении, а аргумент — значение в вызове.
- Не пытайся использовать вне функции переменную, которая создана внутри неё: локальная переменная существует только внутри функции.

<Callout kind="mistake">Прежде чем перейти дальше после цикла, ответь на два вопроса: какая переменная меняется на каждом проходе и приближает ли она цикл к условию окончания?</Callout>

## Коротко

- Инструкции выполняются по порядку, поэтому неверный порядок даёт неверный результат.
- Ветвление выбирает один блок из цепочки условий.
- Цикл while повторяется, пока условие истинно, и подходит для неизвестного числа повторов; цикл for подходит для известного числа.
- Бесконечный цикл возникает, когда условие окончания никогда не выполняется.
- Функция принимает параметры, получает аргументы при вызове и может вернуть значение.
- Модульность разбивает код на функции, которые можно повторно использовать и проверять.
