## Суть

Программы хранят значения в переменных, задают каждому значению тип данных, меняют текст строковыми методами, обрабатывают неожиданные события с помощью обработки исключений и ищут ошибки инструментами отладки. Большинство вопросов просят проследить программу: предсказать, что делает каждая строка с переменными, шаг за шагом, и точно назвать вывод.

## Объяснение

### Переменные и типы данных

<Term id="b2-1-variable"/> — это именованная область памяти, которая хранит значение. Python не требует объявлять переменную до её использования, поэтому достаточно написать total = 10. У каждого значения всё равно есть <Term id="b2-1-data-type"/>, который определяет, что оно может хранить и какие операции допустимы. Нужно знать такие типы: int — целое число, например 29; float — число с десятичной точкой, например 7.99; bool — True или False; str — строка символов, например "Nadia". Отдельного типа для символа в Python нет, поэтому один символ — это str длиной 1.

Выбор типа — это решение о точности. Идентификатор, который может начинаться с нуля, стоит хранить как строку, потому что у числа ноль пропадёт. Оценку 6,5 нельзя хранить как целое число: int(6.5) даёт 6, и половина балла теряется.

### Глобальные и локальные переменные

<Term id="b2-1-global-variable"/> создаётся вне любой функции и доступна для чтения в любом месте программы. <Term id="b2-1-local-variable"/> создаётся внутри функции, существует только во время её работы и не может использоваться за её пределами. Когда функция присваивает значение имени, Python создаёт локальную переменную с этим именем, если только имя не объявлено как global. Ключевое слово global позволяет функции изменить глобальную переменную. Когда вы прослеживаете программу, выпишите каждую переменную с её областью действия и отдельно следите за глобальными и локальными значениями.

### Работа со строками

<Term id="b2-1-string"/> — это набор символов, которые нумеруются с 0: в "Old Town" под индексом 4 стоит T. Срез [start:end] возвращает символы от start до end, не включая end. find возвращает первый индекс подстроки или -1, если её нет, а rfind — последний индекс. replace меняет все вхождения, если не задано количество замен, а split превращает строку в список слов. Соединение строк с помощью + — это <Term id="b2-1-concatenate"/>. Оно работает только со строками, поэтому число сначала нужно преобразовать через str().

### Обработка исключений

Исключение — это неожиданное событие во время работы программы, например когда пользователь вводит буквы вместо числа или файл не существует. <Term id="b2-1-exception-handling"/> — это приём, при котором рискованный код помещают в блок try, а ошибку обрабатывают в блоке except, чтобы программа могла продолжить работу. Блок finally выполняется независимо от того, возникла ли ошибка, поэтому именно там удобно закрыть файл или вывести завершающее сообщение. Программы также предотвращают ошибки заранее, например с помощью проверки диапазона, выбора из списка или проверки наличия знака @ в адресе электронной почты.

### Отладка

<Term id="b2-1-debugging"/> — это поиск и исправление ошибок. Труднее всего найти логические ошибки: программа работает без исключений, но даёт неверный ответ, например из-за неправильных скобок, неверного диапазона цикла, повторно использованного имени переменной или бесконечного цикла. Помогают четыре приёма. <Term id="b2-1-trace-table"/> записывает переменные и решения на каждом шаге, поэтому видно первое неверное значение. Оператор print показывает, какая ветка или какой проход цикла выполняются, и значение переменной в этом месте. <Term id="b2-1-breakpoint"/> приостанавливает программу на выбранной строке, чтобы проверить значения, а пошаговое выполнение проходит код по одной строке и показывает переменные.

## Разбор примера

Школа хранит адреса электронной почты. Эта программа берёт имя пользователя до знака @ и домен после него. Предскажите три строки вывода до запуска.

```python
# Прочитать школьный адрес электронной почты и разделить его по знаку @.
email = "anna.petrova@school.example"
at = email.find("@")
if at == -1:
    print("Invalid email")
else:
    name = email[:at]
    domain = email[at + 1:]
    print(name)
    print(domain)
    print(name.upper() + " at " + domain)
```

Вызов find возвращает 12, позицию знака @. Срез email[:12] сохраняет всё до него, а email[13:] начинается на одну позицию после @, поэтому сам знак @ не входит в домен. Проверка на -1 обрабатывает адрес без знака @. Выведенные строки: anna.petrova, school.example и ANNA.PETROVA at school.example.

<Callout kind="mistake">Ждать, что обработка исключений исправит неверный ответ. Логическая ошибка не вызывает исключения, поэтому её ищут с помощью таблицы трассировки, операторов print или точки останова.</Callout>

## Коротко

- Переменная — это именованная область памяти; её тип определяет, что она может хранить и какие операции допустимы.
- Python не требует объявлений, но int, float, str и bool по-прежнему важны для точности и для доступных операций.
- Глобальная переменная доступна везде; локальная существует только внутри своей функции; ключевое слово global позволяет функции изменить глобальную переменную.
- Строки можно индексировать, срезать, искать, заменять и разделять; конкатенация соединяет их с помощью +.
- Обработка исключений с помощью try, except и finally справляется с неожиданными событиями; она не исправляет логические ошибки.
- Отладка использует таблицы трассировки, операторы print, точки останова и пошаговое выполнение, чтобы найти первое неверное значение.
