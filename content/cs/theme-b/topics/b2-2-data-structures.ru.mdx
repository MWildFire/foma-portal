## Суть

Структура данных — это способ хранить много значений так, чтобы с ними было удобно и быстро работать: читать, менять и искать. Выбор зависит от того, известно ли заранее число элементов и в каком порядке их добавляют и удаляют. В этой теме вы сравниваете статические и динамические структуры, пишете программы со списками и объясняете, как стеки (last in, first out) и очереди (first in, first out) управляют доступом к элементам.

## Объяснение

**Статическая или динамическая.** <Term id="b2-2-static-data-structure"/> имеет размер, который задают при объявлении, на этапе компиляции, и который не меняется, пока программа работает. <Term id="b2-2-dynamic-data-structure"/> не требует задавать размер заранее: память отводится по мере добавления элементов и освобождается, когда их удаляют. Представьте книжную полку ровно на десять ячеек, это статическая структура, и корзину для покупок, в которую кладут сколько угодно товаров, это динамическая.

**Как выбрать.** Сравнивайте три вещи. Гибкость: статическая структура подходит, когда число элементов известно, а динамическая, когда оно неизвестно. Память: динамическая структура занимает только нужный объём, а статическая резервирует весь свой размер, даже если часть элементов пуста. Скорость: статическая структура обычно немного быстрее при прямом доступе к элементу по индексу, потому что память динамической структуры может стать фрагментированной, и это замедляет доступ.

**Массивы, кортежи и Python.** В Java <Term id="b2-2-array"/> является статической структурой, а ArrayList — динамической. В Python <Term id="b2-2-tuple"/> имеет фиксированный размер, и его элементы нельзя изменить, а список всегда динамический.
**Списки и индексы.** <Term id="b2-2-list"/> хранит несколько элементов под одним именем. Каждый элемент имеет <Term id="b2-2-index"/>, и в программировании первый элемент имеет индекс 0, а не 1. В Python элемент добавляют методом append(), удаляют по значению методом remove(), а по индексу — оператором del. Обойти все элементы по очереди (<Term id="b2-2-traversal"/>) можно циклом с индексом или циклом for, который берёт каждый элемент напрямую.

**Двумерные списки.** <Term id="b2-2-two-dimensional-list"/> — это список строк, поэтому его удобно нарисовать как таблицу. В Python элемент в строке r и столбце c записывается как grid[r][c]. Двойной цикл обходит все элементы: внешний цикл проходит по строкам, а внутренний — по столбцам.

**Стеки.** <Term id="b2-2-stack"/> работает по принципу «последним пришёл — первым ушёл». Операция push добавляет элемент наверх, pop удаляет верхний элемент, а peek показывает верхний элемент, не удаляя его. Каждая из этих операций занимает постоянное время, O(1), потому что трогается только верхний элемент. Добраться до элемента на дне можно только за O(n), ведь сначала нужно удалить все элементы над ним. Полный стек фиксированного размера вызывает ошибку переполнения стека (stack overflow). Стеки применяются в рекурсии, для проверки парности скобок, для отмены действий и для переворачивания строки.

**Очереди.** <Term id="b2-2-queue"/> работает по принципу «первым пришёл — первым ушёл». Элементы встают в конец (enqueue), уходят из начала (dequeue), а первый элемент можно посмотреть методом front(). Удаление первого элемента занимает O(1), а удаление последнего — O(n), потому что перед ним должны уйти все остальные. Задания печати и плейлисты — привычные примеры очередей.

<Callout kind="tip">Обычный список в Python хорошо подходит как стек: методы append() и pop() работают с концом списка за постоянное время. Для очереди берите collections.deque: его метод popleft() удаляет первый элемент за постоянное время, а list.pop(0) сдвигает все оставшиеся элементы на одну позицию.</Callout>

## Разбор примера

Программа ниже ведёт список товаров на складе, меняет его и затем обходит. Проследите каждую строку и запишите список после каждого изменения, прежде чем смотреть результат.

```python
stock = ["pens", "paper", "glue"]
stock.append("rulers")
stock.remove("paper")
del stock[0]
for index, item in enumerate(stock):
    print(index, item)
print(len(stock))
```

<Steps>
<Step>append("rulers") добавляет новый элемент в конец: ["pens", "paper", "glue", "rulers"].</Step>
<Step>remove("paper") удаляет первый элемент, значение которого равно "paper": ["pens", "glue", "rulers"].</Step>
<Step>del stock[0] удаляет элемент с индексом 0, то есть первый: ["glue", "rulers"].</Step>
<Step>enumerate выдаёт каждый элемент вместе с его индексом, поэтому в каждой строке печатаются два значения.</Step>
</Steps>

<Reveal title="Показать вывод">Вывод: 0 glue, затем 1 rulers, затем 2 (длина списка).</Reveal>

Командные слова этой темы:

- **Проведите различие (Distinguish)**: покажите разницу между двумя понятиями, например между статической и динамической структурой.
- **Обоснуйте (Justify)**: приведите верные причины выбора, например какая структура подходит для описанной ситуации.
- **Нарисуйте (Sketch)**: изобразите структуру с подписанными элементами, например стек после нескольких операций push и pop.
- **Дайте определение (Define)**: точный смысл термина. Пример и объяснение не нужны.
- **Укажите (State)**: короткий ответ, например вывод программы, без объяснения.
- **Объясните (Explain)**: подробный ответ с причинами, например почему полный стек фиксированного размера может переполниться.
- **Вычислите (Calculate)**: числовой ответ с показанными этапами, например таблица трассировки.
- **Составьте (Construct)**: полный рабочий код на Python, когда просят написать программу или метод.

<Callout kind="exam">Ответ на задание «Составьте» оценивают по логике. Проверьте, что индекс остаётся в пределах списка, что цикл заканчивается и что каждая операция работает с нужным концом: для стека — с вершиной, для очереди — добавление в конец и удаление из начала.</Callout>

## Типичные ошибки

- Не думай, что содержимое статической структуры нельзя менять. Фиксирован только размер: элементы массива в Java можно менять, а элементы кортежа в Python — нельзя.
- Не начинай счёт с 1. Первый элемент имеет индекс 0, а последний — на единицу меньше длины списка.
- Не пиши grid[столбец][строка]. В записи grid[строка][столбец] сначала идёт строка.
- Не путай порядок стека и очереди. Стек отдаёт самый последний добавленный элемент, а очередь — самый давний.
- Не пиши цикл по range(len(список) + 1): последний индекс выйдет за пределы списка, и программа выдаст ошибку.
- Не думай, что список в Python должен хранить данные одного типа. Он может содержать разные типы, в отличие от ArrayList в Java.

<Callout kind="mistake">Запомни два правила: стек — «последним пришёл, первым ушёл» (LIFO), а очередь — «первым пришёл, первым ушёл» (FIFO). Для каждой операции определи, с какого конца она работает.</Callout>

## Коротко

- Статическая структура имеет размер, заданный при компиляции; динамическая растёт и уменьшается, пока программа работает.
- Список хранит много элементов под одним именем, а индексы начинаются с 0.
- Обходите список циклом с индексом или циклом for по элементам.
- Двумерный список — это список строк, к элементу обращаются как grid[строка][столбец].
- Стек работает по принципу LIFO: push, pop и peek действуют на вершине и занимают O(1) времени.
- Очередь работает по принципу FIFO: enqueue — в конец, dequeue — из начала; удаление первого элемента занимает O(1) времени.
