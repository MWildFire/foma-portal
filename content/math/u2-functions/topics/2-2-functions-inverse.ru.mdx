## Суть

Функция сопоставляет каждому аргументу из области определения ровно одно значение. Обратная функция обращает взаимно однозначное соответствие между областью определения и областью значений. Её график получается отражением исходного графика относительно $y=x$.

## Объяснение

<Term id="function-single-output"/> задаёт одно значение для каждого допустимого аргумента. В записи $f(x)$ буква $f$ обозначает функцию, $x$ — аргумент, а вся запись $f(x)$ — соответствующее значение. Разным аргументам могут соответствовать одинаковые значения, поэтому обратная функция существует не у каждой функции на всей её области определения.

<Term id="domain-and-range-of-function"/> — множества допустимых аргументов и действительно принимаемых значений. Для $f(x)=\sqrt{x-2}$ на наибольшей действительной области определения это $[2,\infty)$ и $[0,\infty)$ соответственно. Контекст может сузить множества. Время, прошедшее от указанного начала, неотрицательно; временная координата относительно другой точки отсчёта может быть отрицательной. Количество отдельных предметов целое, если явно не введена непрерывная модель.

<Term id="inverse-function-reflection"/> $f^{-1}$ существует как функция из области значений $f$ в её область определения, если каждое принимаемое значение получается ровно при одном аргументе. Например, $x^2$ на всей числовой прямой не удовлетворяет этому условию: при 2 и −2 значение равно 4. После ограничения $x\ge0$ обратной становится функция $\sqrt{x}$.

<Formula id="inverse-composition-identity"/>

Для $f(x)=ax+b$, где $a\neq0$, запишите $y=ax+b$, поменяйте переменные местами: $x=ay+b$. Затем выразите $y=(x-b)/a$.

<Formula id="inverse-linear-function"/>

Функция $e^x$ взаимно однозначно отображает действительную ось на положительную полуось. Её обратная — $\ln x$ с областью определения $x>0$ и областью значений, равной всей действительной оси.

<Formula id="inverse-exponential-log"/>

<Callout kind="define">Если $f(b)=a$, то обратная функция даёт $f^{-1}(a)=b$. Её область определения совпадает с областью значений $f$, а область значений — с областью определения $f$. Эти множества — часть ответа.</Callout>

Точка $(a,b)$ исходного графика переходит в $(b,a)$ обратного. Точка $(c,c)$ при отражении остаётся на месте; это не означает, что все точки прямой $y=x$ принадлежат обоим графикам.

<Callout kind="gdc">На странице Graphs постройте исходную функцию, найденную обратную с нужной областью определения и прямую $y=x$ для сравнения отражённых графиков. Чтобы найти $f^{-1}(a)$, решите $f(x)=a$ в исходной области определения через Numerical Solve либо найдите пересечение $y=f(x)$ с $y=a$. Проверьте единственность решения в этой области: один численный результат сам по себе её не доказывает.</Callout>

## Разбор примера

В условной задаче стоимость изготовления $n$ сумок равна $C(n)=4{,}5n+12$ AED для целых $n\ge0$. Сначала продолжим правило до непрерывной модели $\widetilde C(x)=4{,}5x+12$ для действительных $x\ge0$, затем рассмотрим бюджет 100 AED.

<Steps>
<Step>$C(20)=4{,}5\times20+12=102$: двадцать сумок стоят 102 AED.</Step>
<Step>Для непрерывной модели после перестановки переменных уравнение $y=4{,}5x+12$ принимает вид $x=4{,}5y+12$. Поэтому $\widetilde C^{-1}(x)=(x-12)/4{,}5$ при $x\ge12$.</Step>
<Step>$\widetilde C^{-1}(100)=88/4{,}5\approx19{,}56$. Это порог непрерывной модели, а не достижимое количество сумок и не значение обратной к исходной дискретной функции: число 100 не входит в её область значений.</Step>
<Step>Решим $4{,}5n+12\le100$ при целом $n\ge0$. Наибольшее допустимое количество — 19. Проверяем: $C(19)=97{,}5\le100$, но $C(20)=102>100$.</Step>
</Steps>

<Reveal title="Почему непрерывный порог нельзя округлить вверх?">Здесь нужно выполнить неравенство бюджета, а не округлить к ближайшему целому. Двадцать сумок стоят дороже бюджета. Проверка соседних целых количеств показывает, что 19 — наибольшее допустимое значение.</Reveal>

## Визуально

При отражении относительно $y=x$ координаты каждой точки меняются местами. График дискретной стоимости состоит из отдельных точек; таким же будет график обратной функции. Непрерывная модель — часть прямой при $x\ge0$, а её обратная — часть прямой с аргументами не меньше 12. Различайте эти графики при поиске порога бюджета.

<Callout kind="tip">Проверяйте обе композиции и множества: $f^{-1}(f(x))=x$ для $x$ из исходной области определения и $f(f^{-1}(y))=y$ для $y$ из исходной области значений. Проверка нескольких чисел помогает обнаружить ошибку, но не доказывает тождество на всей области.</Callout>

## Как это спрашивают

Укажите нужные области определения и значений, покажите преобразования или численное уравнение и объясните результат в контексте. Ограничение должно иметь конкретную причину. Точная схема баллов за метод и рассуждение зависит от задания.

<Callout kind="exam">Проверьте смысл переменной. Количество отдельных предметов целое; временная координата может быть отрицательной, а время от указанного начала — нет. Аргумент обратной функции должен входить в область значений исходной.</Callout>

## Типичные ошибки

<Callout kind="mistake">Обратная функция $f^{-1}(x)$ и обратная величина $1/f(x)$ различаются. Для $f(x)=2x$ обратная функция равна $x/2$, а обратная величина — $1/(2x)$ там, где она определена.</Callout>

- Заявлять об обратной функции на области, где два аргумента дают одно значение.
- Отражать график относительно оси вместо прямой $y=x$.
- Не указывать область определения обратной или принимать порог непрерывной модели за достижимое дискретное значение.

## Коротко

- Каждому допустимому аргументу функция сопоставляет одно значение.
- Обратная функция существует между областью значений и областью определения, если разным аргументам соответствуют разные значения.
- Перестановка координат отражает график относительно $y=x$.
- Проверяйте обе композиции и их области определения.
- Различайте дискретную обратную функцию и непрерывный порог бюджета.
