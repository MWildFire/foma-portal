## Суть

Метод Эйлера численно следует за полем направлений. Из начальной точки он идёт по касательной на фиксированный шаг $h$, считает наклон в новой точке и повторяет. Так получаются приближённые значения $y$ при равноотстоящих значениях $x$.

## Объяснение

<Term id="euler-method-first-order"/> превращает поле направлений в числа. Начиная с точки $(x_0, y_0)$, он проходит короткий отрезок по касательной, считает наклон в новой точке и повторяет. В результате получается приближённое решение в наборе точек, а не формула для кривой.

<Callout kind="define">Метод Эйлера: численный метод, который приближает решение $dy/dx = f(x, y)$ от заданной начальной точки, повторяя шаг $y_{n+1} = y_n + h\,f(x_n, y_n)$.</Callout>

Каждый шаг — это отрезок касательной в начале шага:

<Formula id="euler-step-first-order"/>

Горизонтальное расстояние $h$ — это <Term id="euler-step-length-first-order"/>. Поскольку он фиксирован, $x_n = x_0 + nh$, и если уменьшить $h$ вдвое, для того же $x$ понадобится вдвое больше шагов.

Погрешность возникает, потому что кривая отклоняется от касательной. Для $dy/dx = x - y$ при $y(0) = 1$ на отрезке $0 \le x \le 1$ кривая выгибается вверх, поэтому касательная на каждом шаге лежит ниже кривой, и оценки Эйлера отстают от точного решения. Уменьшение $h$ вдвое примерно вдвое уменьшает погрешность.

В общем случае, если кривая выгибается вверх ($d^2y/dx^2 > 0$), оценки Эйлера обычно занижены, а если вниз — обычно завышены.

## Разбор примера

Используйте метод Эйлера для $\dfrac{dy}{dx} = x - y$ с $y(0) = 1$ и $h = 0{,}2$ от $x = 0$ до $x = 1$. Точное решение $y = x - 1 + 2e^{-x}$ позволяет оценить погрешность.

<Steps>
<Step>Из точки $(0, 1)$ наклон равен $0 - 1 = -1$, поэтому $y_1 = 1 + 0{,}2(-1) = 0{,}8$ при $x_1 = 0{,}2$.</Step>
<Step>Из точки $(0{,}2;\; 0{,}8)$ наклон равен $0{,}2 - 0{,}8 = -0{,}6$, поэтому $y_2 = 0{,}8 + 0{,}2(-0{,}6) = 0{,}68$ при $x_2 = 0{,}4$. То же правило даёт $y_3 = 0{,}624$, $y_4 = 0{,}6192$ и $y_5 = 0{,}65536$ при $x_5 = 1$.</Step>
<Step>Точное значение $y(1) = 2e^{-1} = 0{,}736$ (с точностью до 3 знаков после запятой). Оценка Эйлера $0{,}655$ (с точностью до 3 знаков после запятой) занижена, погрешность $0{,}080$. При $h = 0{,}1$ оценка равна $0{,}697$, а погрешность $0{,}038$; при $h = 0{,}05$ погрешность падает до $0{,}019$.</Step>
</Steps>

<Steps>
<Step>Возьмём $\dfrac{dx}{dt} = y$ и $\dfrac{dy}{dt} = t - x$ с $x = 1$ и $y = 0$ при $t = 0$ и $h = 0{,}5$. Первый шаг даёт $x_1 = 1 + 0{,}5(0) = 1$, $y_1 = 0 + 0{,}5(0 - 1) = -0{,}5$ и $t_1 = 0{,}5$.</Step>
<Step>Из $t = 0{,}5$ оба обновления используют $x_1 = 1$ и $y_1 = -0{,}5$: $x_2 = 1 + 0{,}5(-0{,}5) = 0{,}75$ и $y_2 = -0{,}5 + 0{,}5(0{,}5 - 1) = -0{,}75$, поэтому $t_2 = 1$.</Step>
</Steps>

## Как это спрашивают

Баллы обычно даются за метод: один балл за правило $y_{n+1} = y_n + h\,f(x_n, y_n)$ с верными числами, один за перенос значений от шага к шагу и один за итоговое значение с нужной точностью. Сначала проверьте число шагов: от $x = 0$ до $x = 1$ при $h = 0{,}2$ будет пять шагов. Чтобы определить, завышена или занижена оценка, обоснование должно опираться на кривизну решения, а не на размер ответа.

<Callout kind="exam">Держите полные значения на протяжении всех шагов и округляйте только итоговый ответ. Округление на каждом шаге может изменить последний знак.</Callout>

## Типичные ошибки

<Callout kind="mistake">Использовать значение в конце шага, чтобы найти наклон для того же шага. Метод Эйлера берёт наклон в начале каждого шага.</Callout>

- Неверно считать шаги: от $x = 0$ до $x = 1$ при $h = 0{,}2$ нужно пять шагов, а не четыре.
- Принимать $h$ за изменение $y$. Это изменение $x$.
- Для системы использовать новое $x$, чтобы вычислить новое $y$ на том же шаге. При $t = 0{,}5$, $x = 1$ и $y = -0{,}5$ верное значение $y_2 = -0{,}75$; если взять новое $x_2 = 0{,}75$, получится неверное $-0{,}625$.

## Коротко

- Метод Эйлера на каждом шаге движется по касательной в начале шага: $y_{n+1} = y_n + h\,f(x_n, y_n)$.
- Ведите одну строку на шаг и держите полные значения до итогового ответа.
- Для системы обновляйте $x$, $y$ и $t$ вместе, используя только значения в начале шага.
- Уменьшение шага вдвое примерно вдвое уменьшает погрешность метода.
- Если кривая выгибается вверх, оценка обычно занижена; если вниз, обычно завышена.
- Число шагов равно длине отрезка, делённой на $h$.
