## Big idea

Every rounded number stands for a range of exact values. Good answers keep track of that range: they state the bounds, the meaningful digits and the size of the error, rather than trusting one rounded value.

## Explanation

Treat a measurement reported to a stated number of <Term id="significant-figures"/> as rounded unless the value is explicitly exact. Significant figures are counted from the first non-zero digit, so the zeros before 4 in 0.0047 are not significant. Decimal places count only the digits after the point.

A value $a$ rounded to $d$ decimal places comes from an exact value $x$ within half a unit of the last decimal place. For the nonnegative measurements here, use nearest rounding with midpoint ties upwards: the lower endpoint is included and the upper is excluded. Other tie conventions may change endpoint inclusion. The ends are the <Term id="bounds-of-rounded-value"/>:

<Formula id="rounding-bounds"/>

Intersect this interval with any stated physical constraints. For example, a nonnegative mass reported as 0.0 kg has $0\le x<0.05$ kg, not a possible negative mass.

When measured values are combined, the bounds of the result come from the bounds of the inputs. For positive independent inputs, product bounds use both lower or both upper endpoints, and quotient bounds use opposite endpoints; the denominator must stay positive. An excluded upper endpoint gives a supremum, not an attained maximum. With negative inputs, test the signs and endpoint combinations: for $x\in[-3,-2]$ and $y\in[4,5]$, the product ranges from $-15$ to $-8$, not from multiplying only both lower and both upper values. If a denominator interval contains zero, the quotient may be undefined or unbounded.

## Worked example

A rectangular plot is 12.4 m long and 8.6 m wide, each correct to 1 decimal place. Find the bounds of the length and of the area. Then find the percentage error when 3.6 is used for the true value 3.75.

<Steps>
<Step>Length: half a unit of the first decimal place is 0.05, so the bounds are $12.4 - 0.05 = 12.35$ and $12.4 + 0.05 = 12.45$. The length $L$ satisfies $12.35 \le L < 12.45$.</Step>
<Step>Width: the bounds are 8.55 and 8.65. The exact area bounds are $12.35\times8.55=105.5925$ and $12.45\times8.65=107.6925$, so $105.5925\le A<107.6925$ square metres. The upper bound is not attained. If a containing interval to two decimal places is required, round outwards: $105.59\le A<107.70$, not $A<107.69$.</Step>
<Step>Percentage error when 3.6 is used for the true value 3.75: $\dfrac{|3.6 - 3.75|}{3.75} \times 100 = 4.00\%$ (to 2 decimal places).</Step>
</Steps>

<Reveal title="Why the modulus sign?">Errors can be above or below the exact value. The absolute convention used here makes the error magnitude nonnegative, including zero for an exact match. The booklet also displays a signed relative-error form: preserve a sign when that is requested. An exact value of zero does not define a relative percentage error.</Reveal>

## Visual

The rounded value can be drawn as a short interval on a number line. The exact value sits somewhere inside it, and the two bounds are the ends of that interval. Sketch the interval for each rounded value before you combine them, so that you can see which bounds give the largest or the smallest result.

<Callout kind="tip">Mark the bounds of every rounded measurement on a number line, then pick the upper or the lower bound for each factor to get the largest or smallest result.</Callout>

## How it is examined

Check the actual allocation: there is no universal mark for each bound or for its decimal places. Preserve exact bounds or round outwards when a containing interval is required. Estimate questions reward a sensible rounding to one significant figure and a clear comparison. Comment questions need a conclusion based on the bounds, not a repeat of a calculated value.

<Callout kind="exam">Keep full accuracy in the working and round only the final answer, unless the question asks you to round an intermediate step.</Callout>

## Common mistakes

<Callout kind="mistake">Writing the bounds of 12.4 as 12.3 and 12.5. The half unit is 0.05, so the bounds are 12.35 and 12.45.</Callout>

- Taking the largest rounded values as the upper bound of a quotient, instead of the upper bound of the top and the lower bound of the bottom.
- Dividing by the approximate value instead of the exact value when finding a percentage error.
- Counting the leading zeros of 0.0047 as significant figures. It has two significant figures.

## Summary

- A value $a$ rounded to $d$ decimal places has the bounds $a - \frac{1}{2} \times 10^{-d}$ and $a + \frac{1}{2} \times 10^{-d}$; for the nonnegative midpoint-up convention, the lower bound is included and the upper is not.
- Significant figures are counted from the first non-zero digit, so leading zeros never count.
- For positive independent factors, the product endpoints come from both lower or both upper inputs; excluded endpoints need not be attained.
- For positive inputs and a denominator bounded away from zero, an upper quotient bound uses the upper numerator and lower denominator.
- Absolute percentage error is the absolute difference divided by the absolute nonzero exact value, times 100%; distinguish the booklet’s signed convention.
- Estimate by rounding each value to one significant figure, and round only the final answer.
