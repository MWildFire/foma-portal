Представление данных и компьютерная логикаData representation and computer logic

Эта тема (A1.2) — про то, как компьютер «думает» нулями и единицами. Мы разберём системы счисления (двоичная, десятичная, шестнадцатеричная), как в битах кодируются числа, текст, изображения, звук и видео, как из крошечных логических элементов (AND, OR, NOT, NAND, NOR, XOR, XNOR) собираются процессоры, и как таблицы истинности и логические диаграммы помогают проектировать и проверять цифровые схемы. На уровне HL ещё добавляются карты Карно (Karnaugh maps) для упрощения булевых выражений. This topic (A1.2) is about how a computer “thinks” in zeros and ones. We cover number systems (binary, denary, hexadecimal), how numbers, text, images, sound and video are encoded in bits, how logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) are combined into processors, and how truth tables and logic diagrams help to design and check digital circuits. At HL, Karnaugh maps (K-maps) are also covered for simplifying Boolean expressions.

🔢 1. A1.2.1 Системы счисления (number systems)🔢 1. A1.2.1 Number systems

Любая система счисления — это просто способ записывать числа. Привычная нам система — десятичная (denary, base-10) — использует 10 цифр (0–9). Компьютеры внутри работают с двоичной (binary, base-2) — всего 2 цифры (0 и 1). А программисты часто читают и пишут адреса памяти и цвета в шестнадцатеричной (hexadecimal, base-16) — 16 «цифр» (0–9 и A–F). Any number system is simply a way of writing numbers. The one we use every day is denary (base 10), which uses 10 digits (0–9). Inside computers, binary (base 2) is used, with only 2 digits (0 and 1). Programmers often read and write memory addresses and colours in hexadecimal (base 16), which has 16 “digits” (0–9 and A–F).

To show which number system is meant, a subscript is added: 1110, 112 and 1116 are three different numbers (eleven, three and seventeen respectively).

1.1 Двоичная система (binary)1.1 Binary (base 2)

Каждая позиция бита соответствует степени двойки. Считаем справа налево: самый правый бит — это 20 = 1, следующий 21 = 2, дальше 22 = 4, 23 = 8 и так далее. Чтобы получить десятичное значение — складываем все степени двойки, где стоит 1. Each bit position is a power of two. Count from right to left: the rightmost bit is 20 = 1, the next is 21 = 2, then 22 = 4, 23 = 8, and so on. To get the denary value, add up all the powers of two where there is a 1.

Сколько чисел помещается в N бит?How many values fit in N bits?

В N бит можно записать ровно 2N разных значений (от 0 до 2N − 1, если беззнаковое): In N bits you can represent exactly 2N different values (from 0 to 2N − 1 if unsigned):

  • 4 бита → 24 = 16 значений (0–15) → один ниббл, одна hex-цифра4 bits → 24 = 16 values (0–15) → one nibble, one hex digit
  • 8 бит → 28 = 256 значений (0–255) → один байт8 bits → 28 = 256 values (0–255) → one byte
  • 16 бит → 216 = 65 536 значений16 bits → 216 = 65 536 values
  • 32 бита → 232 ≈ 4,29 млрд значений32 bits → 232 ≈ 4.29 billion values

Hex is a human-readable way of writing binary numbers. Each hex digit = exactly 4 bits. This is very convenient: a long bit string 11010110 becomes the short D6.

1.3 Зачем вообще hex?1.3 Why use hex at all?

  • Короче. 32 бита = 8 hex-цифр, а не 32 нуля и единицы — проще читать и не путать.Shorter. 32 bits = 8 hex digits, not 32 zeros and ones, so it is easier to read and harder to mix up.
  • Прямая связь с битами. 4 бита = 1 hex-цифра, и переход «туда-обратно» — это просто таблица.Direct link to bits. 4 bits = 1 hex digit, and converting back and forth is simply a table.
  • Используется везде: цвета в CSS (#FF00AA), MAC-адреса (3C:22:FB:..), адреса памяти, кодировки Unicode (U+0041).Used everywhere: colours in CSS (#FF00AA), MAC addresses (3C:22:FB:..), memory addresses, Unicode code points (U+0041).

💾 2. A1.2.2 Как двоичная система хранит данные💾 2. A1.2.2 How binary stores data

Внутри компьютера всё — числа, текст, картинки, звук, видео — это просто последовательность бит. Различные схемы кодирования объясняют, как эти биты надо интерпретировать. Дальше — по типам данных. Inside a computer, everything (numbers, text, pictures, sound, video) is just a sequence of bits. Different encoding schemes explain how these bits should be interpreted. Next, by data type.

Старший (самый левый) бит становится знаковым (sign bit): 0 = положительное, 1 = отрицательное. В N битах помещаются значения от −2N−1 до 2N−1 − 1.The leftmost (most significant) bit becomes the sign bit: 0 = positive, 1 = negative. In N bits you can store values from −2N−1 to 2N−1 − 1.

  1. Запиши абсолютную величину в двоичном виде (с нужным числом бит).Write the absolute value in binary (with the required number of bits).

Проверка: старший бит = 1 (отрицательное). Чтобы прочитать величину обратно — снова инвертируй и прибавь 1: 11111011 → 00000100 → +1 → 00000101 = 5. ✓Check: the leftmost bit = 1 (negative). To read the magnitude back, invert again and add 1: 11111011 → 00000100 → +1 → 00000101 = 5. ✓

💡 Почему two's complement? Потому что в этой системе сложение и вычитание работают одинаково для положительных и отрицательных чисел — процессору не нужны отдельные схемы для «минусов». Один сумматор справляется со всем. 💡 Why two’s complement? In this system addition and subtraction work the same way for positive and negative numbers, so the processor does not need separate circuits for negative numbers. One adder handles everything.

2.3 Изображения (images) и цвет RGB2.3 Images and RGB colour

Изображение — это сетка крошечных квадратиков, пикселей (pixels). Чем больше пикселей — тем выше разрешение (resolution) и тем больше деталей. An image is a grid of tiny squares, pixels. The more pixels there are, the higher the resolution and the more detail there is.

Цвет каждого пикселя в модели RGB задаётся комбинацией трёх каналов: красный (Red), зелёный (Green), синий (Blue). Обычно на каждый канал — 1 байт (8 бит), значит 256 уровней яркости (0–255). Итого один пиксель = 3 байта = 24 бита — это «истинный цвет» (true colour, 24-bit colour depth). The colour of each pixel in the RGB model is set by a combination of three channels: red, green and blue. Each channel usually uses 1 byte (8 bits), which gives 256 brightness levels (0–255). So one pixel = 3 bytes = 24 bits. This is “true colour” (24-bit colour depth).

Звук в природе — аналоговый (плавно меняющаяся волна). Чтобы записать его цифрой, его «нарезают» на дискретные точки. Sound in nature is analogue (a smoothly changing wave). To record it digitally, it is “cut up” into discrete points.

Чем выше частота дискретизации и битовая глубина — тем точнее цифровая копия звука, но и тем больше места он занимает. The higher the sampling rate and bit depth, the more accurate the digital copy of the sound, but the more space it takes up.

2.5 Видео (video)2.5 Video

Видео = последовательность кадров (frames), каждый из которых — обычная картинка из пикселей. К кадрам добавляется аудиодорожка (тоже оцифрованная), потом всё это мультиплексируется (объединяется), чтобы аудио и видео шли синхронно. Video = a sequence of frames, each of which is an ordinary picture made of pixels. An audio track (also digitised) is added to the frames, and then all of it is multiplexed (combined) so that the audio and video run in sync.

⚡ 3. A1.2.3 Логические элементы (logic gates)⚡ 3. A1.2.3 Logic gates

Логический элемент (logic gate) — это электронная схема (из транзисторов), которая берёт один или несколько двоичных входов и выдаёт один двоичный выход по строгому правилу. В мире «1» = True = on (есть напряжение), «0» = False = off (нет напряжения). A logic gate is an electronic circuit (made of transistors) that takes one or more binary inputs and produces one binary output according to a strict rule. In digital circuits, “1” = True = on (voltage present), “0” = False = off (no voltage).

Логические элементы — это физическое воплощение булевой алгебры. Из их комбинаций строится всё: сумматоры, регистры, контроллеры, в конечном счёте — процессор. Logic gates are the physical form of Boolean algebra. Everything is built from combinations of them: adders, registers, controllers and, in the end, the processor.

📊 4. A1.2.4 Таблицы истинности (truth tables)📊 4. A1.2.4 Truth tables

Таблица истинности — это полный список всех возможных комбинаций входов и соответствующих выходов схемы. Это главный инструмент, чтобы предсказать поведение логической схемы или построить схему из словесного описания. A truth table is a complete list of all possible input combinations and the matching outputs of a circuit. It is the main tool for predicting the behaviour of a logic circuit, or for building a circuit from a written description.

4.1 Сколько строк должно быть в таблице?4.1 How many rows must the table have?

Если в схеме N входов, то возможных комбинаций 2N: If a circuit has N inputs, there are 2N possible combinations:

  • 1 вход → 2 строки1 input → 2 rows
  • 2 входа → 4 строки2 inputs → 4 rows
  • 3 входа → 8 строк3 inputs → 8 rows
  • 4 входа → 16 строк4 inputs → 16 rows
💡 Как заполнять входы: идите по строкам, как будто считаете двоично от 0. Для 3 входов A, B, C первая строка 000, потом 001, 010, 011, 100, 101, 110, 111. Так ничего не пропустите. 💡 How to fill in the inputs: go down the rows as if you were counting in binary from 0. For 3 inputs A, B, C the first row is 000, then 001, 010, 011, 100, 101, 110, 111. This way you will not miss any.

4.4 Карты Карно (Karnaugh maps, K-maps) HL4.4 Karnaugh maps (K-maps) HL

Карта Карно (Karnaugh map / K-map) — это специальный визуальный способ упростить булево выражение. По сути это «перерисованная» таблица истинности, но с такой раскладкой строк и колонок, чтобы соседние ячейки отличались ровно одним битом (это называется код Грея / Gray code). A Karnaugh map (K-map) is a special visual method for simplifying a Boolean expression. In effect it is a redrawn truth table, but with the rows and columns arranged so that neighbouring cells differ by exactly one bit (this is called a Gray code).

Как построить K-map для двух переменныхHow to build a K-map for two variables

  3. В каждую ячейку запишите выход Q для соответствующей пары (A, B).Write the output Q for the matching pair (A, B) in each cell.

Правила группировки единиц:Rules for grouping 1s:

  1. Группы — это степени двойки (1, 2, 4, 8 единиц), прямоугольной формы.Groups are powers of two (1, 2, 4 or 8 ones) and have a rectangular shape.
  2. Делайте группы как можно больше.Make the groups as large as possible.

This is part of hardware optimisation.

  4. Запишите результат — это и есть полная двоичная запись вашего имени в ASCII / UTF-8.Write down the result. This is the full binary form of your name in ASCII / UTF-8.
  5. Бонус: возьмите символ, которого нет в ASCII (например, «ё», «ñ», «あ») и сравните: в UTF-8 он займёт 2–3 байта, а не один. Обсудите, почему UTF-8 переменной длины — удачное решение для интернета.Bonus: take a character that is not in ASCII (for example, “ё”, “ñ”, “あ”) and compare: in UTF-8 it takes 2–3 bytes, not one. Discuss why UTF-8 with variable length is a good solution for the internet.

🏠 Домашнее задание: Цифровая аналогия дома🏠 Homework: a digital analogy for the home

Цель: Понять булеву логику через метафору повседневной жизни.Goal: understand Boolean logic through an analogy from everyday life.

  1. Опиши, какие правила работают в твоём собственном доме (или придумай для воображаемого) в виде логических выражений. Например:Describe which rules work in your own home (or invent them for an imaginary one) as logical expressions. For example:
    • «Свет в холле зажигается, если кто-то открыл дверь OR датчик движения сработал».“The hall light turns on if someone has opened the door OR the motion sensor has triggered.”
    • «Включить кондиционер, если температура > 26 °C AND (дома кто-то есть OR подключился умный режим)».“Switch on the air conditioner if the temperature > 26 °C AND (someone is at home OR the smart mode is switched on).”
    • «Сигнализация активна, если (никого нет дома) AND NOT (приехала уборщица)».“The alarm is active if (nobody is at home) AND NOT (the cleaner has arrived).”
  2. Для каждого правила построй таблицу истинности.For each rule, build a truth table.
  3. Для одного из правил нарисуй логическую диаграмму.For one of the rules, draw a logic diagram.
  4. Бонус: где в твоих правилах появляется XOR или XNOR? Часто это «либо одно, либо другое — но не оба».Bonus: where do XOR or XNOR appear in your rules? Often it is “either one or the other, but not both”.

🎯 Что важно запомнить🎯 Key points to remember

  • Биты — это всё. Числа, текст, картинки, звук, видео — в памяти лежит просто длинная последовательность 0 и 1. Разница только в схеме кодирования.Bits are everything. Numbers, text, pictures, sound and video are all just a long sequence of 0s and 1s in memory. The only difference is the encoding scheme.
  • Степени двойки наизусть: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024 — экономит время на экзамене.Powers of two by heart: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024. This saves time in the exam.
  • Hex ↔ Binary — это таблица из 16 строк. Один ниббл (4 бита) = одна hex-цифра. Никаких делений.Hex ↔ Binary is a 16-row table. One nibble (4 bits) = one hex digit. No division needed.
  • Two's complement: старший бит = знак, отрицание = «инвертируй биты + 1». Диапазон N-битного знакового: от −2N−1 до +2N−1 − 1.Two’s complement: the leftmost bit is the sign; negation = “invert the bits + 1”. The range of an N-bit signed integer: from −2N−1 to +2N−1 − 1.
  • RGB пиксель = 3 байта (24 бита) для «истинного цвета». Размер несжатой картинки = ширина × высота × глубина цвета.An RGB pixel = 3 bytes (24 bits) for “true colour”. The size of an uncompressed image = width × height × colour depth.
  • Звук: sampling (Hz) задаёт частоту замеров, bit depth — точность каждого замера. CD = 44,1 кГц, 16 бит.Sound: the sampling rate (Hz) sets how often measurements are taken, and bit depth sets the precision of each measurement. CD = 44.1 kHz, 16 bits.
  • Семь логических элементов: AND (все на 1), OR (хоть один на 1), NOT (инверсия), NAND/NOR (отрицание AND/OR — универсальные), XOR (входы разные), XNOR (входы равны).Seven logic gates: AND (all inputs 1), OR (at least one input 1), NOT (inversion), NAND/NOR (negated AND/OR, universal), XOR (inputs differ), XNOR (inputs are equal).
  • NAND и NOR универсальны — из одних только NAND или одних только NOR можно собрать любую цифровую схему.NAND and NOR are universal: any digital circuit can be built from NAND gates alone or from NOR gates alone.
  • Таблица истинности: N входов → 2N строк. Заполняй входы как двоичный счётчик и используй промежуточные столбцы для сложных выражений.Truth table: N inputs → 2N rows. Fill in the inputs like a binary counter and use intermediate columns for complex expressions.
  • K-map (HL): группы единиц степенями двойки, как можно больше; переменная исчезает из терма, если меняется внутри группы.K-map (HL): group the 1s in powers of two, as large as possible; a variable drops out of a term if it changes within the group.
  • На диаграмме: кружок на выходе = NOT. Подписывай все входы и выходы.On a diagram: a circle at the output = NOT. Label all inputs and outputs.
  • Булева алгебра упрощает схемы — меньше элементов = быстрее, дешевле, меньше тепла.Boolean algebra simplifies circuits: fewer gates = faster, cheaper, less heat.
  • На экзамене: вопрос «опиши работу X» — отвечай через входы, выходы и что элемент спрашивает; вопрос «упрости» — выноси общий множитель, ищи (X OR NOT X) = 1.In the exam: for “describe how X works”, answer in terms of the inputs, the outputs and what the gate asks; for “simplify”, factor out a common term and look for (X OR NOT X) = 1.
